账号是独立的表

一台电脑 × 一个平台可以登记多个号，当前 只有一个。新增不会再覆盖旧号；删掉当前号会自动顺延同池的第一条。

写入走同一条接口

所有改动都是 POST /api/records 或 PATCH，服务端维护不变量，前端只做展示。

POST /api/records
{
  "db": "accounts",
  "properties": {
    "账号名": { "text": "坤坤-小号" },
    "平台": { "select": "WorkBuddy" },
    "所属电脑": { "text": "4070S" }
  }
}

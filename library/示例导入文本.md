# 批量导入 · 示例长文本

把下面这段（按你的实际情况改）粘进工作台顶栏「批量导入」即可。
首次使用建议先粘这一小段试试手感。

```text
## 电脑（新建）
机器名：4070S
位置：Office

## 电脑（新建）
机器名：4070TiSuper
位置：Home

## 任务（新建）
标题：示例任务：从零开始的第一条
电脑：4070S
优先级：P1
状态：进行中
进度：建好了电脑，写下第一条任务
待办：
[x] 登记电脑
[ ] 写下第一条任务
[ ] 试试批量导入的手感

## 同步（新建）
仓库：Simiely/agent-workbench
电脑：4070S
版本：v1.10.1
内容：资料库版首次启用
状态：已同步
```

## 两种卡片，别写混

| 块头 | 写到哪张看板 |
|---|---|
| `## 任务（新建）` / `## 任务（更新）` | 任务看板 |
| `## 同步（新建）` | GitHub 同步看板 |

## 续写已有卡片

先点顶栏「复制提示词」，现状里每张卡开头带 `#t1` 这样的 id，照抄：

```text
## 任务（更新）
编号：t1
进度：这次又做了什么
待办：
[x] 照抄现状里的待办原文
```

**待办要照抄原文**——系统按原文匹配改勾选，改写措辞会追加出重复项。

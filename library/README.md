# library/ · 资料库版（WorkBuddy 资料包）

> 给 WorkBuddy 资料库用的单文件工作台。**HTML 负责呈现，CSV 负责存数据**。
> 打开是空壳四表，从零录入；可随时导出成 4 个 CSV 备份或迁移，也能把 CSV 导回来。

## 目录内容

| 文件 | 说明 |
|---|---|
| `agent-workbench-资料库版.html` | **主文件**，双击即可用（单文件自包含，无需 Node） |
| `awb-tasks.csv` | 任务台账 · 11 列 |
| `awb-machines.csv` | 机器登录态 · 5 列 |
| `awb-accounts.csv` | 登录账号 · 8 列 |
| `awb-github.csv` | GitHub 同步记录 · 10 列 |
| `接数据源提示词.md` | 想接资料库双向同步时，整段复制发给 WorkBuddy |
| `示例导入文本.md` | 批量导入的长文本示例，可直接粘进工作台试 |
| `示例-走查导入内容.txt` | 一次真实走查的导入内容（3 个块，实测 0 报错） |

## 快速开始

1. WorkBuddy → 左侧「资料库」→ 选一个空间
2. 上传 `agent-workbench-资料库版.html`
3. 双击打开即用

想跨设备同步，见 `接数据源提示词.md`。

## 三件套怎么分工

| 载体 | 角色 |
|---|---|
| HTML（本文件） | 界面与交互：任务看板、GitHub 看板、批量导入、搜索 |
| CSV（4 个文件） | 数据底座：备份、迁移、批量改数据 |
| MD（本文件） | 说明与口径 |

改数据改 CSV，改样子改 HTML，互不干扰。

## 日常用法

### 录入（两种方式）

| 方式 | 适合 |
|---|---|
| 页面上手写 | 一两条、随手记 |
| 顶栏「批量导入」 | 一次写多条、让 AI 回写 |

批量导入流程：顶栏「复制提示词」→ 粘给 AI → AI 按格式回一段长文本 →
顶栏「批量导入」粘贴 → **先出预览清单**，确认后才落库。

> 提示词里带工作台现状（电脑 / 任务 / 待办原文 / 仓库），AI 据此判断该新建还是续写。
> 定位用卡片 id（`#t1` 这类），**不要用位置序号**——数据一增一删就位移。

### 备份与迁移（顶栏「CSV」按钮）

- **导出 4 个 CSV** — 标准 CSV（UTF-8 BOM，Excel 可直接打开）
- **导入 CSV 文件** — 可多选，按文件名认表，只覆盖导入的那几张表
- **清空全部数据** — 四表清空（先弹确认，建议先导出备份）

**文件名约定**：文件名里要含表名（tasks / machines / accounts / github），
默认导出是 `awb-tasks.csv` 这类，改名时别把表名改没了。

## 字段口径（改 CSV 前先看）

| 字段 | 取值 |
|---|---|
| `状态` | 进行中 / 已完成 |
| `优先级` | P0 / P1 / P2 |
| `平台` | WorkBuddy / TRAE |
| `是否同步` | 已同步 / 未同步 |
| `当前` / `仓库归档` / `仓库置顶` | 是 / 否（或 true / false） |

写错会被拦下并说明原因，**不会静默写脏**。

⚠️ machines 的 `WorkBuddy账号` / `TRAE账号` 是**派生只读**（由 accounts 表的「当前」算出），
CSV 里没有这两列，接表格时也不要建。

## 两个必须知道的边界

### 1. 数据默认落「本机浏览器」

- ✅ 同浏览器、同电脑，关掉再打开还在
- ⚠️ **换浏览器 / 换设备 / 清缓存，不会自动跟随**

要跨设备或长期留档：**用「导出 4 个 CSV」**，把 CSV 放进资料库——
CSV 在云端，那才是真正的持久化与多端同步。

### 2. 真正的「改 CSV、页面自动刷新」需要平台注入表格 ID

官方轻应用是「HTML 通过表格 ID 实时读 CSV」双向同步，但表格 ID 是平台内部注入的，
外部拿不到。想接上走 `接数据源提示词.md`，不接也能用（就是上面第 1 条的本机存储）。

## 和普通版的区别

| | 资料库版（本目录） | 普通版（`node server.mjs`） |
|---|---|---|
| 启动 | 双击打开 | 需要 Node 起服务 |
| 数据落点 | 浏览器本地 + CSV 导出 | `../agent-workbench-data/db.json` |
| 多端同步 | 靠 CSV 放进资料库 | 同一台机器 |
| 适合 | 资料库里随时打开、随手记 | 本地长期使用 |

两边数据格式一致，**可以用 CSV 互相搬运**。

# 接 CSV 数据源 · 直接复制给 WorkBuddy

> 这一步我替你做不了——表格 ID 是平台在生成时内部注入的，需要你在 WorkBuddy 客户端里操作。
> 下面这段提示词粘进去，WorkBuddy 会自己完成接入。**整段复制**，方括号里按实际改。

## 第一步：把文件放进资料库

1. WorkBuddy → 左侧「资料库」→ 选一个空间
2. 上传 `agent-workbench-资料库版.html`
3. 再上传 4 个 `awb-*.csv`（可以先只传空的模板，也可以先不传，让 WorkBuddy 按下面提示词自己建）

## 第二步：复制这段提示词发给 WorkBuddy

```
请把这个 Agent 工作台接上资料库的 CSV 表格，实现数据在线存储和双向同步。

【文件】
- HTML：资料库里的 agent-workbench-资料库版.html
- CSV：awb-tasks.csv / awb-machines.csv / awb-accounts.csv / awb-github.csv
  （如果还没有这 4 个 CSV，请先按下面「数据形状」建好，字段一次定死）

【现在的问题】
这个 HTML 的数据目前存在浏览器 localStorage（key 是 awb.offline.db.empty），
换浏览器或换设备数据就不在了。我要改成：数据在资料库云端，多端同步。

【数据形状】一张表 = 一个 CSV，一条记录 = 一行，一个字段 = 一列
- tasks：_id / 任务标题 / 状态 / 优先级 / 所在电脑 / 目录 / 进度 / 待办 / 交接内容 / 更新时间 / 排序
- machines：_id / 机器名 / 位置 / 最后确认 / 排序
  ⚠️ 不要给 machines 建「WorkBuddy账号」「TRAE账号」两列——它们是派生只读值，
     由 accounts 表算出，存储里不留第二份
- accounts：_id / 账号名 / 平台 / 所属电脑 / 当前 / 备注 / 最后确认 / 排序
- github：_id / 同步时间 / 电脑 / GitHub账号 / 仓库 / 内容 / 同步版本 / 是否同步 / 仓库归档 / 仓库置顶

【写入前必须校验】
- 状态 = 进行中 / 已完成；优先级 = P0 / P1 / P2
- 平台 = WorkBuddy / TRAE；是否同步 = 已同步 / 未同步
- 当前 / 仓库归档 / 仓库置顶 = 布尔
- 必填：tasks[任务标题,状态,优先级,所在电脑]  machines[机器名]
       accounts[账号名,平台,所属电脑]       github[电脑,仓库]
写错要拦下并说明原因，不要静默写脏。

【必须保留的能力，改的时候别弄丢】
- 顶栏「复制提示词」：带工作台现状骨架（电脑/任务/待办原文/仓库），AI 据此判断新建还是续写
- 顶栏「批量导入」：AI 回写长文本 → 预览清单 → 确认后落库
- 顶栏「CSV」面板：导出 4 个 CSV / 导入 CSV / 清空
- 搜索同时检索任务看板与 GitHub 看板
- 手机窄屏下栏顶不置顶
- 定位用卡片 id（#t1 这种），不要用位置序号

【验收】
1. 在 CSV 里改一条数据，回 HTML 刷新，页面要跟着变
2. 在 HTML 上新增一条记录，回 CSV 看，表格里要出现这一行
3. 两边都通了才算接上，只通一边不算
```

## 第三步：验收

按提示词最后的验收清单走：

| 动作 | 预期 |
|---|---|
| CSV 里改一条 → HTML 刷新 | 页面跟着变 |
| HTML 新增一条 → 看 CSV | 表格多一行 |

**两边都通才算接上。** 只通一边要继续跟 WorkBuddy 说，别将就。

## 接不上怎么办

常见卡点：

- **页面永远是空的** —— 多半是表格没绑上。绑定在导入/关联参数里，不在页面代码里，最容易漏。
  跟 WorkBuddy 说：「确认一下 HTML 和 4 个 CSV 的关联有没有建立」
- **往单选字段写表里没有的值被拒** —— 枚举必须严格照抄上面那几组取值
- **CSV 中文乱码** —— 编码必须是 UTF-8，不要用 Excel 直接打开保存（会变 GBK）

---

## 不接也能用

不接的情况下数据落本机浏览器，同浏览器同电脑没问题，换设备不会跟随。
要跨设备就**用「导出 4 个 CSV」把数据放进资料库**——CSV 在云端，那才是持久化。
